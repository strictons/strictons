# Homepage photographs

The logo and Lillie Nolan painting are already connected. The other four image
spaces intentionally stay blank until these photographs are added here:

| Filename              | Photograph                                 | Display ratio    |
| --------------------- | ------------------------------------------ | ---------------- |
| `hotel-dining.jpg`    | Guests dining by the water at sunset       | 1.27:1 landscape |
| `guide-reception.jpg` | Receptionist handing a guest the guide     | 367:435 portrait |
| `guide-car.jpg`       | Guide on a car seat with travel belongings | 367:435 portrait |
| `guide-bookshelf.jpg` | Guide displayed on a bookshelf             | 367:435 portrait |

Use these exact lowercase names. `.jpeg`, `.png`, and `.webp` also work with the
same base names (keep just one version of each photo). Photos are cropped to fill
their frame; use at least 1200 pixels wide for crisp displays. Restart the dev
server or rebuild the site after adding assets. No code changes are needed.
